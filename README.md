# RideLink - CBSD Component Repository

Component-Based Software Development (CBSD) assignment repository for the RideLink carpooling platform.

This repository contains the component refactoring, design pattern implementations, and architectural improvements applied to the RideLink Final Year Project as part of the CBSD course assessment.

## Project Structure

```
ridelink_app/   # Flutter mobile app (Dart)
backend/        # Express.js + Convex backend (TypeScript)
```

## Design Patterns Implemented

- **Repository Pattern** — Decouples data access from state management
- **Observer Pattern** — Provider/ChangeNotifier for reactive UI updates
- **Interceptor Pattern** — Auth and response unwrapping in ApiClient
- *(more patterns added weekly)*
